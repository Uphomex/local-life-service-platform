## 二、依赖服务安装

### 2.1 MySQL安装

**Windows系统：**

1. 下载MySQL 8.0安装包：https://dev.mysql.com/downloads/mysql/
2. 安装过程中设置root密码为 `root`
3. 创建数据库和用户：

```sql
CREATE DATABASE local_life_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'admin'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON local_life_db.* TO 'admin'@'localhost';
FLUSH PRIVILEGES;
```

**Linux系统（Ubuntu/Debian）：**

```bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql

# 设置密码和创建用户
mysql -u root -p
# 输入密码后执行
CREATE DATABASE local_life_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'admin'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON local_life_db.* TO 'admin'@'localhost';
FLUSH PRIVILEGES;
```

### 2.2 Redis安装

**Windows系统：**

1. 下载Redis：https://github.com/tporadowski/redis/releases
2. 解压到 `D:\redis`
3. 启动Redis：

```cmd
cd D:\redis
redis-server.exe redis.windows.conf
```

**Linux系统：**

```bash
sudo apt install redis-server
sudo systemctl start redis-server
sudo systemctl enable redis-server
```

### 2.3 Kafka安装

**Windows系统：**

1. 下载Kafka：https://www.apache.org/dyn/closer.cgi?path=/kafka/2.8.1/kafka_2.13-2.8.1.tgz
2. 解压到 `D:\kafka`
3. 启动Zookeeper：

```cmd
cd D:\kafka\bin\windows
zookeeper-server-start.bat ..\..\config\zookeeper.properties
```

4. 启动Kafka（新窗口）：

```cmd
cd D:\kafka\bin\windows
kafka-server-start.bat ..\..\config\server.properties
```

**Linux系统：**

```bash
# 安装Java（如果未安装）
sudo apt install openjdk-11-jdk

# 下载并解压Kafka
wget https://downloads.apache.org/kafka/2.8.1/kafka_2.13-2.8.1.tgz
tar -xzf kafka_2.13-2.8.1.tgz
mv kafka_2.13-2.8.1 /opt/kafka

# 启动Zookeeper
cd /opt/kafka
bin/zookeeper-server-start.sh config/zookeeper.properties &

# 启动Kafka
bin/kafka-server-start.sh config/server.properties &
```

## 三、后端服务启动

### 3.1 数据库初始化

**方法一：自动初始化（推荐）**

项目启动时会自动执行数据库脚本，确保配置文件中有以下配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/local_life_db?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&createDatabaseIfNotExist=true
```

**方法二：手动执行SQL**

```bash
cd backend/src/main/resources/db
mysql -u admin -p local_life_db < schema.sql
mysql -u admin -p local_life_db < data.sql
```

### 3.2 Maven依赖安装

```bash
cd backend
mvn clean install -DskipTests
```

### 3.3 启动后端服务

**开发模式：**

```bash
cd backend
mvn spring-boot:run
```

**打包部署：**

```bash
cd backend
mvn clean package
java -jar target/local-life-service-platform-1.0.0.jar
```

## 七、常见问题排查

### 7.1 数据库连接失败

**问题：**
```
Cannot get connection, pool error Timeout waiting for idle object
```

**解决方案：**
1. 检查MySQL服务是否启动
2. 检查数据库连接配置是否正确
3. 检查防火墙是否允许3306端口

### 7.2 Redis连接失败

**问题：**
```
Unable to connect to Redis
```

**解决方案：**
1. 检查Redis服务是否启动
2. 检查Redis绑定地址（bind 0.0.0.0）
3. 检查是否需要密码认证

### 7.3 Kafka连接失败

**问题：**
```
Connection to node -1 could not be established. Broker may not be available.
```

**解决方案：**
1. 确保Zookeeper已启动
2. 检查Kafka配置文件中的listeners
3. 等待Kafka完全启动

### 7.4 前端跨域问题

**问题：**
```
Access-Control-Allow-Origin header missing
```

**解决方案：**
1. 确保后端配置了CORS
2. 检查Vite代理配置

### 7.5 端口占用

**问题：**
```
Address already in use
```

**解决方案：**
```bash
# Windows
netstat -ano | findstr :8080
taskkill /F /PID <PID>

# Linux
lsof -i :8080
kill -9 <PID>
```
