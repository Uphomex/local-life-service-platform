### 2.1 启动类

**文件位置：** `backend/src/main/java/com/example/life/LocalLifeServiceApplication.java`

```java
@SpringBootApplication
```

**关键点说明：**

| RiderController | `controller/RiderController.java` | 骑手管理 |

**示例：AuthController**

```java
@RestController
@RequestMapping("/api/auth")
public class AuthController {
    private final UserService userService;
    
    @PostMapping("/login")
    public ResponseEntity<ResponseResult<LoginResponse>> login(@Valid @RequestBody LoginRequest request) {

        return ResponseEntity.ok(ResponseResult.success(response));
    }
}
```

### 2.5 服务层

服务层包含业务逻辑，分为接口和实现类。

| 服务接口 | 实现类 | 功能说明 |
|----------|--------|----------|
| UserService | UserServiceImpl | 用户认证逻辑 |
| MerchantService | MerchantServiceImpl | 商家管理逻辑 |
| ProductService | ProductServiceImpl | 商品管理逻辑 |
| OrderService | OrderServiceImpl | 订单处理逻辑 |
| RiderService | RiderServiceImpl | 骑手管理逻辑 |
| ReviewService | ReviewServiceImpl | 评价管理逻辑 |

**示例：UserServiceImpl**

```java
@Service
public class UserServiceImpl implements UserService {
    private final UserMapper userMapper;
    private final PasswordEncoder passwordEncoder;
    private final JwtTokenProvider jwtTokenProvider;
    
    @Override
    public LoginResponse login(LoginRequest request) {
        // 1. 查询用户
        Optional<User> userOptional = userMapper.findByUsername(request.getUsername());
        if (userOptional.isEmpty()) {
            throw new ServiceException(401, "用户名或密码错误");
        }
        
        // 2. 验证密码
        User user = userOptional.get();
        if (!passwordEncoder.matches(request.getPassword(), user.getPassword())) {
            throw new ServiceException(401, "用户名或密码错误");
        }
        
        // 3. 生成Token
        String token = jwtTokenProvider.generateToken(user.getId(), user.getUsername(), user.getRole());
        
        return LoginResponse.builder()
                .userId(user.getId())
                .username(user.getUsername())
                .role(user.getRole())
                .token(token)
                .build();
    }
}
```

### 2.6 数据访问层

数据访问层使用MyBatis Plus，继承`BaseMapper`获得CRUD功能。

| Mapper接口 | 对应实体 | 说明 |
|------------|----------|------|
| UserMapper | User | 用户数据访问 |
| MerchantMapper | Merchant | 商家数据访问 |
| ProductMapper | Product | 商品数据访问 |
| ProductAttributeMapper | ProductAttribute | 商品属性数据访问 |
| ProductSkuMapper | ProductSku | 商品SKU数据访问 |
| OrderMapper | Order | 订单数据访问 |
| OrderItemMapper | OrderItem | 订单项数据访问 |
| RiderMapper | Rider | 骑手数据访问 |
| ReviewMapper | Review | 评价数据访问 |

**示例：UserMapper**

```java
@Mapper
public interface UserMapper extends BaseMapper<User> {
    @Select("SELECT * FROM user WHERE username = #{username}")
    Optional<User> findByUsername(@Param("username") String username);
    
    @Select("SELECT * FROM user WHERE phone = #{phone}")
    Optional<User> findByPhone(@Param("phone") String phone);
}
```

### 2.7 实体类

实体类对应数据库表，使用Lombok简化代码。

**示例：User实体**

```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
@TableName("user")
public class User {
    @TableId(type = IdType.AUTO)
    private Long id;
    
    private String username;
    private String password;
    private String phone;
    private String email;
    private String nickname;
    private String avatar;
    private String role;      // USER, MERCHANT, RIDER, ADMIN
    private String status;    // ACTIVE, INACTIVE
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}
```

**注解说明：**
- `@Data`：自动生成getter/setter/toString等方法
- `@Builder`：构建器模式
- `@TableName`：指定数据库表名
- `@TableId`：主键字段

### 3.4 API封装

**文件位置：** `frontend/src/api/index.ts`

```typescript
const api = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// 请求拦截器 - 添加Token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器 - 处理401
api.interceptors.response.use((response) => {
  return response.data
}, (error) => {
  if (error.response?.status === 401) {
    localStorage.removeItem('token')
    window.location.href = '/login'
  }
  return Promise.reject(error)
})
```
