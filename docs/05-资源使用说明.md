## 三、外部服务资源

### 3.1 数据库服务

**服务名称：** MySQL 8.0+

**配置位置：** `backend/src/main/resources/application.yml`

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/local_life_db?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: admin
    password: password
    driver-class-name: com.mysql.cj.jdbc.Driver
```

**作用说明：**
- 存储用户、商家、商品、订单等核心业务数据
- 支持事务管理
- 支持索引优化

### 3.2 缓存服务

**服务名称：** Redis 6.0+

**配置位置：** `backend/src/main/resources/application.yml`

```yaml
spring:
  redis:
    host: localhost
    port: 6379
    password: password
    timeout: 6000ms
```

**作用说明：**
- 缓存热点数据（商家信息、商品信息）
- 实现分布式锁（库存锁定）
- 存储骑手位置信息
- 缓存会话信息

### 3.3 消息队列服务

**服务名称：** Kafka 2.8+

**配置位置：** `backend/src/main/resources/application.yml`

```yaml
spring:
  kafka:
    bootstrap-servers: localhost:9092
    producer:
      retries: 3
      batch-size: 16384
      buffer-memory: 33554432
    consumer:
      group-id: local-life-service
      enable-auto-commit: true
```

**作用说明：**
- 异步处理订单创建
- 订单状态变更通知
- 骑手分配通知
- 解耦系统组件

## 四、配置文件资源

### 4.1 Spring配置

**文件位置：** `backend/src/main/resources/application.yml`

**主要配置项：**

| 配置项 | 说明 |
|--------|------|
| server.port | 服务端口（默认8080） |
| spring.profiles.active | 激活的配置文件 |
| spring.datasource | 数据库连接配置 |
| spring.redis | Redis连接配置 |
| spring.kafka | Kafka连接配置 |
| mybatis-plus | MyBatis Plus配置 |
| jwt.secret | JWT密钥 |
| jwt.expire-time | JWT过期时间 |
| knife4j.enable | 是否启用API文档 |

**配置文件分类：**

| 文件 | 用途 |
|------|------|
| application.yml | 默认配置 |
| application-dev.yml | 开发环境配置 |
| application-docker.yml | Docker环境配置 |

### 4.2 数据库脚本

**文件位置：** `backend/src/main/resources/db/`

**文件说明：**

| 文件 | 用途 |
|------|------|
| schema.sql | 数据库表结构定义 |
| data.sql | 初始数据（测试账号等） |

**schema.sql内容概览：**

```sql
-- 用户表
CREATE TABLE user (...);

-- 商家表
CREATE TABLE merchant (...);

-- 商品表
CREATE TABLE product (...);

-- 订单表
CREATE TABLE order (...);

-- 骑手表
CREATE TABLE rider (...);

-- 评价表
CREATE TABLE review (...);
```

**服务定义：**

## 六、资源管理最佳实践

### 6.1 依赖管理

1. **版本统一管理**：在pom.xml的properties中定义版本变量
2. **按需引入**：只引入必要的依赖，避免依赖地狱
3. **定期更新**：定期更新依赖版本，修复安全漏洞
4. **排除冲突依赖**：使用exclusions排除冲突的传递依赖

### 6.2 配置管理

1. **环境分离**：不同环境使用不同配置文件
2. **敏感信息加密**：使用Spring Cloud Config或Vault管理敏感配置
3. **配置校验**：启动时校验配置项是否完整
4. **配置热更新**：支持运行时更新配置

### 6.3 外部服务管理

1. **服务健康检查**：定期检查外部服务状态
2. **连接池配置**：合理配置数据库连接池大小
3. **超时配置**：设置合理的连接超时和读取超时
4. **故障降级**：外部服务不可用时的降级策略

### 6.4 资源清理

1. **日志清理**：定期清理日志文件
2. **临时文件清理**：定期清理临时文件
3. **缓存清理**：定期清理过期缓存
4. **连接释放**：确保资源使用后正确释放
